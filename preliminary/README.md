# Preliminary pipeline observations

This directory supports Appendix C. It preserves six scanner-stage counts,
execution metadata, elapsed intervals, database drift and output-quality
observations. The workflow is disabled and is not an active Actions workflow.
The run metadata enumerate 31 workflow runs, including failures. A workflow run
is not necessarily a completed scanner execution.

Reference-evaluation outputs from this phase are outside the article and this
release. They are not replay targets. The final study uses its own versioned
references, measurement gates and five-block campaign; preliminary observations
must not be pooled with that campaign. Historical timestamp and run identifiers
are preserved as provenance identifiers.

The stage-count CSV is a preserved extraction, not a new scanner result. File
integrity and masking records link copies to retained originals. Database
metadata identify the historical snapshots; database payloads are not included.
