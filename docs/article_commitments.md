# Article commitments (verbatim)

## Section 3.7

The public repository and its archived release (Data Availability Statement) contain the protocol and its amendment, the configurations and pinned identities, the code of the pipeline and of the analysis, the stored native reports and the raw model responses. Secret values and session tokens are masked, and a manifest gives, for each masked file, the hash of the original report used by the analysis. With this material, every table and figure can be rebuilt, and the linking of findings to reference instances can be replayed from the scanner reports without running the scanners again.

## Data Availability Statement

The protocol, configurations, pipeline and analysis code, masked scanner reports and raw model responses supporting this study are openly available on GitHub at https://github.com/Yasser-Ag/DevSecOps-pipeline and archived on Zenodo at https://doi.org/10.5281/zenodo.24016866. The OWASP Benchmark test cases are not redistributed; a script in the repository retrieves them at the pinned commit. The unmasked scanner reports are not publicly available because they contain secret values and session tokens; they are available from the corresponding author on reasonable request.
